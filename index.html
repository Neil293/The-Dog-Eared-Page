Keys are stored locally only, never shared. Add either or both — Anthropic is used when set, otherwise Gemini. Get a free Gemini key at aistudio.google.com.

🔥 Firebase Sync

Create a Firebase project at console.firebase.google.com. Enable Firestore Database and Authentication → Sign-in method → Google. Paste config values here and connect, then sign in to sync recipes across devices. Firestore rules: match /users/{uid}/recipes/{id} { allow read, write: if request.auth.uid == uid; }
